# eBay輸出 調査レポート（クラウドワークス発注者データより）

作成: 2026-09-23 / 対象: クラウドワークスで「eBay」を含む募集 1,640件（2025-09〜2026-09）、発注者451人。うち実績のある172人の募集本文を全文読み込み

## 0. 先に結論

- **できる。ただし条件が3つある。** 黒字で続いているセラーは、自分では「判断・仕入れの決済・アカウント操作」しかやっていない。リサーチ・出品・価格調整・顧客対応・発送はすべて在宅ワーカーに件単価で出している。年商9,000万円の桂卓也氏でも、事務は「1日1〜2時間（土日は10〜30分）」
  1. ハンドリングタイム（発送までの日数）を3営業日以上に取り、仕入れと発送を夜と週末に寄せる
  2. 顧客対応と発送は、最初から外注する前提で設計する（相場: 顧客対応 月5,000〜10,000円、発送代行 1件100〜200円）
  3. 新規アカウントの出品上限は **月10品・$500** から始まる。大規模になるまで半年〜1年かかる前提で計画する
- **「募集している＝黒字」は半分しか正しくない。** 2025年中に募集していた187人のうち、2026年7月以降も募集を続けているのは **36人（19%）**。関税で撤退した同業者へのヒアリング募集も2件あった
- **収支の目安（データから逆算）:** 1,000品を出品し、月の販売率3〜5%、1件の利益4,000〜6,800円なら、月の粗利は **12万〜34万円**。外注費とツール代を引くと、手残りは **7万〜24万円**

## 2. 黒字セラーの標準的な仕組み

### 2-1. 業務フロー（無在庫型）

```
[本人] ジャンルとリサーチ条件を決める（利益額・利益率・販売実績）
  ↓
[外注] リサーチ: eBayで売れた商品（Sold / Terapeak）→ 国内（メルカリ・ヤフオク・Amazon・楽天）で同じ商品を探す → 利益計算シートに入力   60〜100円/件 ＋ 売れたら利益の10%
  ↓
[本人] ダブルチェック（利益が出るか・同じ商品か）
  ↓
[外注] 出品: テンプレに沿って入力（タイトルと説明文はChatGPTが作る）   20〜60円/件
  ↓
[外注] 保守: 価格調整（最安値に合わせる） 2〜15円/件、在庫切れ時の仕入れ先差し替え 10〜100円/件
  ↓ 売れる
[本人] 仕入れ（決済）→ 自宅や発送代行者に届く
  ↓
[外注] 検品・梱包・発送 100〜200円/件（在宅の発送代行。保管料 月3,000円の例あり）
[外注] 顧客対応: テンプレ＋AI翻訳、12時間以内に返信   月5,000〜10,000円/人
```

### 2-4. 事業の育ち方（時系列で共通する順番）

1. リサーチを外注（未経験歓迎・高めの単価で試す）
2. 出品を外注
3. 保守（価格調整・在庫補充）を外注。omyahooten: 2月にリサーチ → 4月に価格調整 → 5月に在庫補充
4. 顧客対応を外注（英語ができなくてもAI翻訳とテンプレで回る。YUU03は2交代制）
5. 発送を外注
6. 工程を細かく分けて単価を下げる（bigup 100円 → 60円 → 30円、aki112は自社ツールで判定作業を1件10円に）
7. アカウントを増やす（6アカウントの例あり）／Shopee・Shopifyにも広げる／ツールを開発する（filerは広告率と価格をAPIで自動調整）

### 2-5. ワーカー管理の型

- 募集は「主婦・女性・スキマ時間・長期」。トライアルは5〜20件を有償（数百円）
- 動画とPDFのマニュアル、Chatwork、Zoom面談
- 競業防止: 「自分でeBay販売していない」「他のeBay業務と掛け持ちしない」「アカウント停止歴がない」。ノウハウの持ち出しと、アカウント同士が紐づいてまとめて停止されることの両方を警戒している
- インセンティブは「実利益」で払う（キャンセル・返品分は払わない。MK898）

## 3. 外部条件（クラウドワークスのデータに出てこないもの）

| 論点 | 事実 | 対応 |
|---|---|---|
| eBayの無在庫規約 | 他の小売店やマーケットプレイスで買って **購入者へ直送** するのは禁止。売れてから仕入れ、自分（または代行者）が受け取って検品・発送するのが日本の一般的な形 | 直送は絶対にしない。在庫切れによるキャンセルが続くとアカウントの評価が下がる |
| 新規アカウントの出品上限 | 最初は月10品・$500。毎月の上限引き上げ申請で広げる。2026年からトラストスコアも審査に影響 | 最初の3〜6ヶ月は「規模」ではなく「評価とキャンセル0」を積む期間 |
| 米国の関税 | デミニミス（800ドル以下は関税免除）が廃止。2025年10月17日から、米国宛て2,500ドル以下はDDP（関税をセラーが負担する発送）が必須。「売上の18〜24%が関税と手数料で消える」との記述あり | 利益計算に関税を必ず入れる。高単価の商品に寄せるか、米国以外の市場も狙う |
| 古物商許可 | メルカリなどで中古品を買って売るなら必要（警察署に申請、手数料19,000円）。実績セラーにも古物商番号を掲載している人がいる | 始める前に取る。**サイトへの氏名表示やURLの届出について、匿名運用とぶつかる部分は要確認** |
| 税金 | 確定申告が必要。住民税を「普通徴収」にすれば会社に通知が行きにくい（BSの収入と同じ扱い） | 輸出は消費税が免税になり、課税事業者になれば仕入れ時の消費税の還付を受けられる（年商1,000万円を超えてから検討） |

## 4. あなたが始める場合の設計

### 4-1. 時間の制約をどう潰すか

| 作業 | 誰がやるか | いつ |
|---|---|---|
| ジャンル選び・リサーチ条件・ダブルチェック | 本人（Claudeが補助） | 夜・週末 |
| リサーチ・出品 | 最初の3ヶ月は本人（学ぶため）→ その後クラウドワークスで外注 | 夜 |
| 仕入れ（売れた後の購入） | 本人 | 昼休み・17:15以降。ハンドリングタイム3営業日なら間に合う |
| 検品・梱包・発送 | 本人または **ひなさん**（在宅で日中に動ける。本人の希望が「在宅ワーク」なら候補。ただし本人と相談して決めること）／在宅発送代行 1件100〜200円 | 日中または週末 |
| 顧客対応 | 最初は本人（件数が少ない）→ 月1万円程度で外注 | 12時間以内に返信 |

### 4-2. あなたの差別化: AIで作業単価を下げる

黒字セラーの利益は「リサーチの当たり」で決まり、各社はその作業に1件60〜100円払っている。ChatGPTやGeminiを使い始めた発注者もいるが、まだ「タイトル生成」「翻訳」どまり。Claude Codeで次を自分用に作れば、外注費を下げてリサーチ量を増やせる。

- 商品名を英語の検索語に変換する（美玉は1件7.5円で外注している作業）
- 国内の仕入れ候補との同一商品判定（aki112は1件10円で外注している作業）
- 利益計算シートの自動化（関税・手数料・送料込み）
- 顧客対応の返信下書き（YUU03は月1万円×2人）

ただし **「作る前に売る」** の原則どおり、まず手作業で10品を売り、どこが面倒かを実際に確かめてから作る。

### 4-3. ジャンル候補（仮説。Terapeakで確認する）

| 候補 | 理由 | 確認すること |
|---|---|---|
| バドミントン（ヨネックスの日本版ラケットなど） | 本人の知識がある。リサーチの「当たり」を見分ける目が最初からある | Terapeakで90日の販売数と価格帯。国内の中古・新品との価格差 |
| バイク・自動車部品 | データ上の上位ジャンル（74件）。品番で同じ商品かどうか判定しやすく、AI化しやすい（tsurugi2021、MK898） | 送料（重量）と関税で利益が残るか |
| トレカ・ホビー | 2026年の検索ワードの約28%がトレカ関連。ただし競合が最も多い | 最安値勝負になっていないか |

### 4-4. 段階とゲート

| 段階 | 期間 | やること | 次に進む条件 |
|---|---|---|---|
| 0. 準備 | 2〜4週 | 古物商申請、eBayアカウント作成（ペイオニアの要否も確認）、利益計算シートを作る、ジャンルを1つ決める | 古物商許可とアカウント開設 |
| 1. 手で売る | 1〜3ヶ月目 | 上限10品の範囲で自分でリサーチ・出品・仕入れ・発送。毎月上限引き上げを申請 | 20件販売、赤字0件、セラー都合のキャンセル0件 |
| 2. 外注を入れる | 4〜6ヶ月目 | クラウドワークスで「60円＋利益の10%」のリサーチャーを2〜3人採用（この調査のテンプレをそのまま使う）。発送の担い手を決める | 月の利益5万円 |
| 3. 広げる | 7〜12ヶ月目 | 出品を1,000品へ。保守と顧客対応を外注。自分用のAIツールを入れる | 月の利益15万円 |

**撤退条件:** 6ヶ月で月の利益が3万円に届かない、またはアカウントに制限がかかったら止める。

### 4-5. お金の上限

無在庫でも、売れてから支払いを受け取るまでの仕入れ代金は立て替えになる（新規セラーは入金が遅れやすい）。生活防衛資金150万円の目標と競合するので、**運転資金は20万円を上限にして別口座で管理する**ことを推奨する。

## 5. 注意すべき発注者のタイプ

- スクール・コンサル系（5人）: 「月収5万円以上のメンバー多数」「勉強会」「権利収入」「ストック収入」などの表現。ワーカー募集の形で受講生を集めている疑いがある
- 1件5〜10円の同じ文面の募集: 実体のあるセラーか判別しにくい
- 完了率の低い発注者（+α 87/306など）: ワーカーが定着していない
