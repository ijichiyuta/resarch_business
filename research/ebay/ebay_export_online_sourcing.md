# eBay輸出 ネット仕入れ完結リサーチ（2026年9月版）

調査日: 2026-09-08 / 前提: ネットのみで仕入れが完結する形に限定

## 0. 結論（先に出す）

**本命は「日本の音楽・出版メディア（CD・レコード・書籍）」。** 理由は3つ揃っているから。

1. **米国の関税が免除される唯一のカテゴリ**（informational materials）。他の全カテゴリが10〜12.5%を負担する中で0%
2. **仕入れがネットで完結する**（ブックオフオンライン・駿河屋・ディスクユニオン）
3. **超軽量**（CD1枚250g = 送料1,410円）で、DDP時代に最も有利

そして重要なのは、**日本のeBayセラーの大半がこの事実を認識していない**こと。彼らはカメラ・トレカ・時計に集中していて、関税15%をどう吸収するかで消耗しています。競合が構造的に薄い。

ただし正直に書くと、これは「楽して儲かる」話ではありません。CDの平均単価$106は希少盤が引き上げた数字で、ブックオフの500円CDが$106で売れるわけではない。**どのタイトルが海外で高いかを知っているかどうか**が全てです。逆に言えば、そこはリサーチで詰められるので、あなた向きです。

## 1. 【最重要】2026年9月時点の関税ルール — 前提が変わっている

**ネット上のeBay輸出情報の大半は2025年で止まっていて、現在は通用しません。** 時系列で整理します。

| 時期 | 出来事 |
|---|---|
| 2025年8月29日 | デミニミス（$800免税枠）廃止 |
| 2025年10月17日 | eBayが米国向け$2,500未満のDDP（関税元払い）を義務化 |
| **2026年2月20日** | **最高裁がIEEPA関税を違憲・無効と判断（6-3）** |
| 2026年2月24日 | 代替としてSection 122の一律10%が発動（150日限定） |
| 2026年5月7日 | 国際貿易裁判所がSection 122も無効と判断（政府は控訴中） |
| **2026年7月24日** | **Section 122失効 → Section 301「強制労働関税」に置き換え。日本を含む60カ国が対象、10〜12.5%** |
| 2026年4月14日 | 日本郵便の米国宛が条件付き再開（関税事前払いが条件） |
| 2026年6月24日 | デミニミスの無期限停止が正式ルール化（施行7/24、順守期限10/22） |
| 2026年9月22日 | 郵便向け新通関制度「Entry Type 13」の任意テスト開始予定 |

### 現在の実務上の結論

- **デミニミスは復活していない。** 金額に関わらず全ての商業貨物が正式通関＋関税対象
- **DDP義務化は継続。** DDUを続けるとDefectが付きアカウント制限リスク
- **日本からの一般貨物の関税は10〜12.5%**（Section 301強制労働関税。日本の正確な率は要最終確認 — 情報源によって10%と12.5%で食い違いあり）

### ★そして、免除カテゴリが存在する

**「informational materials（情報資料）」は関税免除。** これは法改正の度に維持されており、根拠が3代にわたって引き継がれています。

| 関税制度 | 免除の根拠 |
|---|---|
| IEEPA時代 | 50 U.S.C. § 1702(b)（バーマン修正条項）。CBPが公式に確認 |
| Section 122 | HTS **9903.03.11**「Articles that are informational materials, including but not limited to publications…」 |
| Section 301強制労働関税（現行） | 一般免除リストに "informational materials" が明記 |

**対象品目**（HTSコード付き）:

| 品目 | HTSコード |
|---|---|
| レコード（アナログ盤） | 8523.80.1000 |
| CD | 8523.49.2000 |
| カセットテープ | 8523.29.4010 |
| 書籍・雑誌・印刷物 | 第49類 |

**対象外**: ポスター、Tシャツ等のマーチャンダイズ（＝「音楽関連グッズ」は免除されない。あくまでメディアそのもの）

> ⚠️ **条件**: 免除を受けるには**HTSコードを正確に申告すること**が必須。誤分類すると免除が効かない。ここは出品時のテンプレートに固定で組み込む。

### これが意味すること

同じ$100の商品を売った場合:

| | カメラ・時計・トレカ等 | CD・レコード・書籍 |
|---|---|---|
| 関税 | $10〜12.5 | **$0** |
| DDPで自己負担 | 必要 | 実質不要 |
| 100件売ったときの差 | — | **$1,000〜1,250の利益差** |

## 8. 落とし穴・法規制（必ず先に潰す）

### 8-1. 古物商許可

- 中古品を**仕入れて売る**なら必須。自分の不用品を売るだけなら不要
- 所轄警察署に申請、**手数料¥19,000、審査約40日**
- **オンライン古物市場の参加に古物商許可証の提示が必須**
- URL届出が必要な場合あり（eBayのストアURL）

### 8-2. 無在庫販売（ドロップシッピング）は原則NG

- eBayは**Retail Dropshipping（他モールで買って購入者へ直送）を明確に禁止**
- 卸契約に基づくドロップシッピングのみ条件付きで許容
- 違反時: **アカウント永久停止＋売上金が最長180日凍結**
- 欠品キャンセル・出荷遅延の繰り返しも危険
- → **ネット仕入れでも「一度自分の手元に入れて検品して送る」有在庫が原則**

### 8-3. HTSコードの正確な申告

- 関税免除は**HTSコードを正確に記載していること**が条件。誤分類すると免除が効かない
- 出品テンプレートに固定で入れる: レコード `8523.80.1000` / CD `8523.49.2000` / カセット `8523.29.4010` / 書籍 第49類

### 8-4. その他

- **VeRO（知的財産）**: アニメ・キャラ系は権利者の削除申請が多い。海賊版・自作グッズは即アウト
- **ワシントン条約**: 象牙、べっ甲、**ローズウッド（ギター等に使用）**は規制対象
- **外為法**: eBay側で通っても、日本の輸出規制品を無許可で送れば法的責任はセラー側
- **新規アカウントでいきなり高額品はNG**（リミット・審査で止まる）
- **補償なし**: 国際エアパケットは補償が付かない。高額品はEMS等を使う
- **DDU継続はDefect対象** → アカウント制限リスク

## 9. 実行前に自分で確認すべき未確認事項

このレポートの前提のうち、**あなた自身が確認しないと危ないもの**を列挙します。

1. **日本に適用されるSection 301の正確な税率** — 情報源が10%と12.5%で食い違っている。CBPの公式CSMSで確認すること
2. **informational materials免除の実運用** — 法令上は免除だが、**実際にCBPが通関でどう処理するか**は別問題。まず1点テスト発送して着金と関税請求の有無を実測する
3. **Section 122の控訴の行方** — 2026年5月にCITが無効判断、政府が控訴中。判決次第で関税制度がまた変わる
4. **eBay側のDDP計算がinformational materialsを正しく0%扱いするか** — eBay/CPaSSが自動で関税を上乗せしてしまうと、免除の利益が消える。**ここが一番の落とし穴になりうる**
5. **為替レート** — 本レポートは¥157/$の仮定。実レートで再計算すること
6. **オンライン古物市場の実際の登録費用・参加条件** — 市場ごとに異なる。エコリング・モノバンク等に直接問い合わせ
7. **CDの平均単価$106の内訳** — 希少盤が引き上げた平均値の可能性が高い。**普通の中古CDがいくらで売れるか**をTerapeakのSoldで実測すること
