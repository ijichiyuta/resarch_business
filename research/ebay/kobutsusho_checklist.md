# 古物商許可 — 警察署 確認チェックリスト

用途: 所轄警察署（生活安全課・防犯係）への事前電話／初回相談で使う
目的: eBayでの中古品輸出（CD・レコード・書籍が主力）＋ 古物市場での仕入れ

---

## 0. 最初に伝える自己紹介（そのまま読める文）

> 「個人で、インターネット（eBay）を使った中古品の輸出販売を始めたいと考えています。
> 古物商許可の申請について、事前に確認させていただきたいことが何点かあります。
> 今お時間よろしいでしょうか。」

補足で聞かれたら:
- **扱う商品** → 「日本の中古CD・レコード・書籍が中心です」
- **仕入れ先** → 「ブックオフなどのリユースショップと、古物市場を予定しています」
- **販売先** → 「eBayを通じて海外のバイヤーに販売します」
- **一般の方からの買取** → 「予定していません」（← 買取をしないなら明言した方が話が早い）

## A. 申請の実務

- [ ] **A-1** 申請は予約制ですか。飛び込みでも대応いただけますか
- [ ] **A-2** 受付の曜日・時間帯を教えてください
- [ ] **A-3** 必要書類の一覧をいただけますか（※署によって追加書類あり）
- [ ] **A-4** 申請書の様式はどこで入手できますか（署でもらう／県警サイトでDL）
- [ ] **A-5** 手数料19,000円の支払い方法は（現金／収入証紙／どこで買うか）
- [ ] **A-6** 審査期間の目安はどのくらいですか
- [ ] **A-7** 許可証の受け取りは本人が行く必要がありますか
- [ ] **A-8** 申請前に書類の事前チェックはしてもらえますか

## B. 営業所 ★一番詰まるところ

- [ ] **B-1** 自宅を営業所にする場合、満たすべき要件はありますか
- [ ] **B-2** 賃貸の場合、賃貸借契約書の写しは必要ですか
- [ ] **B-3** 契約書の「使用目的」が**居住用**になっている場合、どうすればよいですか
- [ ] **B-4** 大家・管理会社の承諾は、書面が必要ですか。口頭でよいですか
- [ ] **B-5** （実家の場合）家族の承諾書は必要ですか
- [ ] **B-6** 審査期間中に、営業所の実地確認はありますか
- [ ] **B-7** 在庫の保管場所が営業所と別でも問題ありませんか

> **持参推奨**: 賃貸なら賃貸借契約書のコピー（使用目的欄をその場で見せられるように）

## C. 取扱品目

- [ ] **C-1** 「主として取り扱う品目＝**道具類**」「取り扱う品目＝**道具類＋書籍**」で申請したいのですが、問題ありませんか
- [ ] **C-2** CD・レコード・DVDは「道具類」でよいという理解で合っていますか
- [ ] **C-3** フィギュア・トレーディングカード・ゲームソフトも「道具類」でよいですか
- [ ] **C-4** 後から品目を追加する場合、手続きと費用はどうなりますか
- [ ] **C-5** 将来カメラ・レンズを扱う場合は「写真機類」の追加でよいですか

## D. 行商・古物市場 ★絶対に外せない

- [ ] **D-1** **「行商する」で申請します**。この選択で問題ありませんか
- [ ] **D-2** 古物市場（業者オークション）に参加する予定です。他に必要な手続きはありますか
- [ ] **D-3** オンラインの古物市場に参加する場合も、同じ扱いでよいですか

> ⚠️ 「行商する」を選ばないと古物市場に参加できない。ここは指差し確認。

- [ ] **E-5** 後からURLを追加・変更する場合の手続きは

## F. 許可後の義務

- [ ] **F-1** 標識（プレート）はどこで購入できますか。指定の様式はありますか
- [ ] **F-2** 古物台帳の様式に指定はありますか。Excel等での電子管理は認められますか
- [ ] **F-3** 一般の方からの買取をせず「仕入れて売るだけ」の場合も、台帳の記録は必要ですか
- [ ] **F-4** 古物市場で仕入れた分の台帳記載はどうすればよいですか

## G. 集める書類（すべて発行から3ヶ月以内）

| 書類 | 取得先 | 済 |
|---|---|---|
| 許可申請書（別記様式第1号） | 警察署 / 県警サイト | ☐ |
| 住民票の写し（**本籍地記載あり・マイナンバー記載なし**） | 市区町村 | ☐ |
| 身分証明書（**本籍地**の市区町村。免許証ではない） | 本籍地の役所 | ☐ |
| 登記されていないことの証明書 | 法務局 | ☐ |
| 略歴書（過去5年分） | 自分で作成 | ☐ |
| 誓約書 | 様式あり | ☐ |
| 営業所の使用権限を示す資料 | 賃貸借契約書の写し等 | ☐ |
| URL使用権限の疎明資料 | eBayアカウント画面等 | ☐ |

> ⚠️ **身分証明書は本籍地の役所でしか取れない**。本籍が遠方なら郵送請求になり1〜2週間かかる。**最初に着手すること。**

## H. 聞かれる可能性があること（答えを準備しておく）

| 質問 | 答え方 |
|---|---|
| どんな商品を扱うか | 日本の中古CD・レコード・書籍。海外向け |
| なぜその品目か | 海外で日本の音楽メディアの需要があるため |
| どこから仕入れるか | リユースショップ、古物市場 |
| 誰に売るか | eBay経由で海外バイヤー |
| 営業所はどこか | （自宅 / 実家の住所） |
| 過去5年の職歴 | 略歴書に記載する内容を整理しておく |
| 一般人から買取をするか | しない（するなら別途ルールがある） |

## K. 絶対に間違えない2点

1. **「行商する」にチェック** — 選ばないと古物市場に入れない
2. **賃貸の使用目的が「居住用」でないか確認** — 該当したら申請前に署へ相談

この2つだけは、申請書を出す前に指差し確認すること。
