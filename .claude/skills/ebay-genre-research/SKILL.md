# eBayジャンル調査

目的は「売れる実績がある × 国内で安く仕入れられる × 送料・関税・手数料を引いても利益が残る」商品群が、そのジャンルに十分あるかを数字で判定すること。印象ではなく、件数と金額で結論を出す。

## 判定の基準（research/ebay/README.md の黒字セラーの基準から）

| 項目 | 合格ライン |
|---|---|
| 販売実績 | 過去90日で2個以上売れている（AOYAMA BASEの基準） |
| 利益額 | 1件3,000円以上（TREE STOREの基準。最低でも1,000円） |
| 利益率 | 10%以上 |
| 価格競争 | eBayの最安値で出しても利益が出る |
| 関税 | 米国向けはDDP（セラーが関税を負担）を前提に計算する |

ジャンル全体の合格ライン: 合格した商品（型番）が **30種類以上** 見つかること。1,000品を並べる事業にするには、同じジャンルで型番を横に広げられる必要がある。

## 手順

1. **仮説の型番リストを作る**（20〜50型番）。ジャンルの知識・eBayの検索候補・競合の日本人セラーのストアから拾う
2. **eBayの販売実績を取る**（ログイン必須）
   - Terapeak: `https://www.ebay.com/sh/research?marketplace=EBAY-US&keywords=<kw>&dayRange=90&tabName=SOLD` で平均販売価格・販売数・送料・売れ率（sell-through）を取る
   - 補助: Sold検索 `https://www.ebay.com/sch/i.html?_nkw=<kw>&LH_Sold=1&LH_Complete=1`（こちらもログイン必須）
   - 発送元が日本のものだけを見る（Item location: Japan）。日本人セラーの販売価格が、実際に自分が売れる価格
3. **国内の仕入れ価格を取る**（ログイン不要）
   - メルカリ（販売中・売り切れ）、ヤフオク（落札相場 `auctions.yahoo.co.jp/closedsearch/closedsearch?p=<kw>`）、Amazon、楽天
   - 状態（新品・中古の程度）と付属品をeBay側とそろえる
4. **利益を計算する**
   ```
   利益 = 販売価格(USD)×為替 − eBay手数料(カテゴリ別の落札手数料＋1件あたりの注文手数料＋国際手数料)
          − 広告費(使う場合) − 国際送料 − 関税(米国DDP) − 仕入れ価格 − 国内送料 − 梱包資材
   ```
   為替と手数料率は調査日の値を記録する。送料は重量と3辺サイズで見積もる（長物・大物は容積重量で跳ねる）
5. **リスクを確認する**
   - VeRO（権利者による出品削除の対象ブランドか）、偽物の多さ、輸出規制・危険物（バッテリー・スプレー・刃物）、米国以外への発送可否
6. **結果を `research/ebay/genres/<ジャンル>.md` に書く**: 型番ごとの表（販売数・平均価格・国内価格・利益・判定）＋ジャンル全体の判定（GO / 条件付き / NO）＋根拠のURL

## ブラウザの使い方（product-scout-skill の検証メモから）

- eBayはボット判定されやすい。検索は間隔を空け、同時に複数タブで叩かない
- 「Pardon Our Interruption」（ボット判定の画面）が出たら止める。条件を変えて連打しない。ユーザーに伝える
- 一覧ページは要点だけ抜き出す（全文のスナップショットは取らない）。価格は商品ページで確かめる（一覧の価格は通貨換算の概算のことがある）
- ログインはユーザー本人が行う。パスワードを聞かない・入力しない
